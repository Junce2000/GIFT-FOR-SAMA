МОБИЛЬНАЯ ВЕРСИЯ ❤️

1. Распакуй zip.
2. Открой index.html — сайт уже сделан под экран телефона.
3. Положи свои фотографии в photos/ и назови:
   photo1.jpg
   photo2.jpg
   photo3.jpg
4. Положи песню рядом с index.html и назови music.mp3.
5. Открой index.html в браузере для теста.

ЧТО МЕНЯТЬ:
- index.html — текст, письмо, воспоминание.
- style.css — цвета/размеры/дизайн.
- script.js — поведение кнопок.

ЧТОБЫ ОНА ОТКРЫЛА С ТЕЛЕФОНА:
Сайт нужно разместить на хостинге. GitHub Pages — бесплатный вариант.
Загрузи файлы в GitHub repository и включи Pages в Settings → Pages.
После этого получишь публичную ссылку.

ВАЖНО:
Музыка в браузерах обычно не запускается автоматически. Поэтому на втором экране есть кнопка "Наша песня".
